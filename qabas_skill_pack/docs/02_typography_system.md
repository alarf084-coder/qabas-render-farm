# نظام الخطوط والتداخل البصري — «قَبسٌ مِنْ أَثر»

## 1. العائلات الست المعتمدة
1. **الضربات الضخمة والشرائط:** `Lalezar` + `Almarai ExtraBold` (للكلمة البطل فوق الشريط النبيتي أو العناوين الصادمة).
2. **السرد التحريري المتباين:** `IBM Plex Sans Arabic` (`300 Light` / `500 Medium` / `700 Bold`) — الوزن `300` يُستخدم قبل الكلمة الضخمة لإحداث تباين بصري حاد.
3. **الهيبة التراثية والكشيدة:** `Amiri` (`Regular` / `Bold` / `Italic`) — للآيات، الأحاديث، الجمل العميقة، وتطويل الكشيدة.
4. **الرقعة الفنية واللوجو:** `Aref Ruqaa Bold` — للوجو «قَبسٌ مِنْ أَثر» والكلمات الانسيابية في الفراغ السلبي بجانب المتحدث.
5. **السطر الروحاني الشاعري:** `Gulzar` — خط نستعليق رقيق يظهر وسط نص عريض بلون `Honey Gold 300/500`.
6. **الكوفي الهندسي والأرقام:** `Reem Kufi` + `Rakkas` — للأرقام (`01 / 02`) والشارات الهندسية وعناوين الفصول.

## 2. قواعد التداخل داخل نفس السطر والمشهد
- يُشترط تغيير **الخط + الوزن + الحجم** معًا عند الانتقال من التمهيد إلى الكلمة المحورية (وليس اللون فقط).
- يُسمح بالكشيدة (`ـ`) في خط `Amiri` و `Lalezar` و `Almarai` لإطالة الكلمة الدرامية؛ وتُمنع الكشيدة في `Aref Ruqaa` حتى لا تتفكك وصلات الرقعة.
- التشكيل يكون **انتقائيًا وصحيحًا لغويًا 100%** على الحروف التي تمنح جمالية وتمنع اللبس، بدون إغراق النص بالحركات.
